# ✠ Имперское Таро

> *«Знание — оружие. Владей им мудро.»*

**Имперское Таро** — терминальный когитатор гадания по варп-сети в сеттинге
**Warhammer 40,000**, написанный на **TypeScript** и поддерживающий толкование
раскладов локальной языковой моделью через **LM Studio**.

Полная колода из **78 священных карт** (22 Старших Аркана, переосмысленных в
лоре Империума, и 56 Младших Арканов четырёх имперских мастей), пять раскладов
варп-сети, ритуал тасования с учётом турбулентности имматериума и голос
Астропата-Прорицателя, толкующего знаки во имя Бога-Императора.

---

## ⚙ Возможности

- 🌐 **Два интерфейса**: терминальный CLI и браузерный **веб-храм** (готическая тема, анимация переворота карт, потоковое толкование).
- 🃏 **78 карт** с прямыми и перевёрнутыми толкованиями, лором WH40k и ключевыми словами.
- 🔮 **5 раскладов**: от «Единого Знака» до «Великого Креста Императора» (10 карт).
- 🌀 **Правила гадания варп-сети**: турбулентность имматериума влияет на частоту
  перевёрнутых карт и на знамение.
- 🤖 **Поддержка LM Studio**: потоковое толкование расклада локальной LLM
  (OpenAI-совместимый API), с мягким **офлайн-резервом**, если сервер недоступен.
- 🎲 **Воспроизводимые гадания** по зерну (`--seed`) — удобно для тестов и повторного прочтения.
- 🎨 **Красивый терминальный вывод**: цвета, панели карт, индикатор турбулентности.
- 🧱 **Ноль рантайм-зависимостей** — только стандартная библиотека Node.

## 📦 Установка

Требуется **Node.js ≥ 20**.

```bash
git clone <repo>
cd Imperskoe-Taro
npm install        # установит devDependencies (typescript, tsx, @types/node)
```

## 🌐 Веб-интерфейс (браузер)

Поднять локальный веб-храм и открыть в браузере:

```bash
npm run web                     # сервер на http://localhost:8080
```

Затем открой **http://localhost:8080**. Веб-интерфейс:

- готическая имперская тема с анимацией переворота карт;
- выбор расклада, вопрос к варпу, индикатор турбулентности;
- **потоковое** толкование от LM Studio прямо в браузере (SSE);
- модальные окна «Правила варп-сети» и «Кодекс карт» (все 78 карт);
- LM Studio **проксируется сервером** — никаких проблем с CORS и без утечки ключей.

> Порт меняется переменной `PORT` (напр. `PORT=8083 npm run web`).
> Это **наш** интерфейс — он не использует никакой платный сторонний API.

## ▶ Запуск CLI (терминал)

Без сборки, прямо из исходников (через `tsx`):

```bash
npm start                       # интерактивный обряд гадания
```

Или собрать и запустить скомпилированный код:

```bash
npm run build
node dist/index.js
```

### Примеры команд

```bash
# Интерактивный обряд (вопрос + выбор расклада + толкование)
npm start

# Неинтерактивное гадание с заданным вопросом и раскладом
npm start -- -q "Ждать ли мне повышения в Адептус Механикус?" -s triptych

# Большой расклад в офлайн-режиме (без LM Studio)
npm start -- --spread great-cross --offline

# Подробное толкование одной карты
npm start -- --card major-04-emperor

# Свод правил гадания варп-сети
npm start -- --rules

# Перечень карт (фильтр: major | minor | aquila | bolter | chalice | blade)
npm start -- --list-cards major

# Проверить LM Studio и перечислить модели
npm start -- --models

# Воспроизводимое гадание и сохранение в JSON
npm start -- -q "Падёт ли крепость?" --seed terra-42 --save reading.json
```

> Двойное `--` нужно, чтобы `npm` передал аргументы скрипту, а не себе.
> При установке пакета как бинарника команда называется `taro`.

## 🤖 Настройка LM Studio

1. Установи и запусти [LM Studio](https://lmstudio.ai/).
2. Загрузи любую chat-модель и запусти локальный сервер
   (**Developer → Start Server**, по умолчанию `http://localhost:1234`).
3. Запусти Имперское Таро — оно само определит сервер и модель.

Конфигурация через переменные окружения (см. `.env.example`):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LMSTUDIO_BASE_URL` | `http://localhost:1234/v1` | URL OpenAI-совместимого API |
| `LMSTUDIO_MODEL` | `auto` | Модель (`auto` — первая загруженная) |
| `LMSTUDIO_API_KEY` | `lm-studio` | Ключ (LM Studio его игнорирует) |
| `LMSTUDIO_TEMPERATURE` | `0.85` | Температура генерации |
| `LMSTUDIO_MAX_TOKENS` | `-1` | Лимит токенов ответа |
| `LMSTUDIO_TIMEOUT_MS` | `120000` | Тайм-аут запроса |

Если LM Studio недоступен, толкование собирается **офлайн** из канонических
значений карт — обряд всегда завершается.

## 🌀 Правила гадания в варп-сети

Полный свод доступен командой `npm start -- --rules`. Ключевые догматы:

1. **Чистота вопрошающего** — один ясный вопрос.
2. **Тройное очищение** — колода тасуется трижды.
3. **Турбулентность имматериума** — от штиля до варп-шторма; влияет на знаки.
4. **Закон перевёрнутых карт** — перевёрнутая карта есть тень и затруднение сути.
5. **Власть позиции** — смысл карты преломляется её местом в раскладе.
6. **Главенство Старших Арканов** — глас судьбы весомее дел земных.
7. **Голос мастей** — преобладающая масть указывает сферу ответа.
8. **Знаки — совет, а не оковы** — Таро являет склонение судьбы, не отменяя воли.

## 🧱 Архитектура

```
src/
  index.ts            — CLI: разбор аргументов и обряд гадания
  tarot/
    types.ts          — онтология карт и раскладов
    suits.ts          — имперские масти и архетипы рангов
    majorArcana.ts    — 22 Старших Аркана
    minorArcana.ts    — генерация 56 Младших Арканов
    deck.ts           — сборка колоды и проверка целостности
    shuffle.ts        — тасование, турбулентность, ориентация карт
    spreads.ts        — определения раскладов
    reading.ts        — проведение гадания
  warp/
    rules.ts          — правила гадания варп-сети и фазы ритуала
  lmstudio/
    config.ts         — конфигурация подключения
    client.ts         — OpenAI-совместимый клиент (fetch, стриминг SSE)
    promptBuilder.ts  — построение промптов толкователя
    interpreter.ts    — оркестрация LM Studio + офлайн-резерв
  cli/
    ansi.ts           — ANSI-цвета
    render.ts         — баннеры, панели карт, правила
    prompts.ts        — интерактивный ввод и ритуальная анимация
  server/
    server.ts         — веб-сервер: статика + API + SSE-проксирование LM Studio
  lib/
    rng.ts            — крипто- и сеяный ГПСЧ
public/               — фронтенд веб-храма
  index.html          — разметка
  styles.css          — готическая имперская тема
  app.js              — клиентская логика (SSE, анимация карт, кодекс)
  aquila.svg          — иконка-аквила
tests/                — испытания (node:test)
```

### API веб-сервера

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/spreads` | Список раскладов |
| `GET` | `/api/cards` | Вся колода (78 карт) |
| `GET` | `/api/cards/:id` | Одна карта |
| `GET` | `/api/rules` | Правила гадания варп-сети |
| `GET` | `/api/health` | Состояние LM Studio |
| `POST` | `/api/divine` | Обряд: расклад + потоковое толкование (SSE) |
